# TechStart Careers — Job Application Form

## Description
A multi-step job application form . It features a dark, premium user interface with a sticky sidebar navigation, an animated progress bar, and smooth transitions between sections.

## Built With
- HTML  
- CSS  
- JavaScript  
- Bootstrap Icons  
- Google Fonts — Syne and DM Sans  

## Features
- 7-step form with sidebar navigation  
- Progress bar that updates as you move through steps  
- Animated background blobs  
- Custom radio pill and checkbox chip inputs  
- Fully responsive design, sidebar hides on mobile  
- Smooth scroll-to-top behavior on section change  

## Project Structure
index.html                  — Markup and form structure  
job-application-styles.css  — All styling  
script.js                   — Section switching logic
